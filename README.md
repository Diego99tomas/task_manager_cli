
A console application developed in Python that allows you to register task, view. With data persistence through JSON files.
---

## 🚀 Features

- Add tasks 
- Automatic priority normalization
- Show listed tasks 


---

## 🛠️ Technologies used

- Python 3
- Object-oriented programming (OOP)
- File handling
- Serialization with JSON
